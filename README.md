# choice4

CSVファイルから4択問題を自動生成して遊べるシンプルなWebアプリケーションです。

## 主な機能

- **CSVからの問題生成**: 1つのCSVファイルに問題文・4つの選択肢・正解番号をまとめて記述し、すぐに4択クイズとして出題できます。
- **サンプルデータのお試し・ダウンロード**: 手元にCSVがなくても「サンプルCSVで試す」ボタンですぐに動作確認でき、テンプレートとなるCSVのダウンロードも可能です。
- **文字コードの自動判定（UTF-8 / Shift-JIS）**: UTF-8での読み込みを基本としつつ、Excel等で保存されたShift-JIS形式のCSVも文字化けを検知して自動で再読み込みします。
- **リアルタイムの正誤フィードバックと進捗表示**: 回答選択時に正解・不正解を色分けとメッセージで表示し、プログレスバーで現在の進行度を確認できます。
- **スコア集計とリトライ機能**: 全問終了後に正解数と正答率を表示し、「同じ問題にもう一度挑戦する」「別のCSVでやり直す」をワンクリックで切り替えられます。

## CSVフォーマット

1行につき1問として記述します（ヘッダー行なし・カンマ区切り）。

| 列 | 内容 | 記述例 |
| :--- | :--- | :--- |
| 1列目 | 問題文 | `日本の首都はどこ？` |
| 2列目 | 選択肢1 | `大阪` |
| 3列目 | 選択肢2 | `京都` |
| 4列目 | 選択肢3 | `東京` |
| 5列目 | 選択肢4 | `札幌` |
| 6列目 | 正解番号（`1`〜`4`） | `3` |

### 記述例

```csv
日本の首都はどこ？,大阪,京都,東京,札幌,3
HTMLで見出しを表すタグはどれ？,p,h1,div,span,2
1バイトは何ビット？,4ビット,8ビット,16ビット,32ビット,2
JavaScriptで定数を宣言するキーワードはどれ？,var,let,const,static,3
CSSで文字色を指定するプロパティはどれ？,background-color,font-size,color,margin,3
HTTPステータスコードで「Not Found」を表すものはどれ？,200,301,404,500,3
```

## 使い方

1. ブラウザで `index.html` を開きます。
2. 「問題のCSVファイルを選択」から用意したCSVファイルをアップロードします（すぐに試したい場合は「サンプルCSVで試す」をクリックします）。
3. 出題される4つの選択肢ボタンから正解だと思うものをクリックします。
4. 正誤の結果を確認し、「次の問題へ」ボタンで進みます。
5. 全問回答すると結果画面が表示され、正解数と正答率を確認できます。
